# ContextAI

An AI assistant that remembers what you tell it, checks live data, reads your PDFs, and shows every step it
takes. This Space runs the Docker image built from
[github.com/vid6848/ContextAI](https://github.com/vid6848/ContextAI), where the code, tests and docs live.
